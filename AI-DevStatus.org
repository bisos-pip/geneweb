* Key Design Decisions
  - v7.1.0-beta2 (user): the newest release and the only one with a published digest; named a beta.
  - gwd only (user): gwsetup cannot bind an address (it would listen on every interface).
  - Wizard password geneweb, no friend password, public pages open (user; rawBisos convention).
  - An empty demo base, created once with gwc (user).
  - Usage side: the GEDCOM and base tools from the same pinned zip (user), as promtool.
  - The zip has no top directory: zipSetupScript unpacks it into installBase/<distName>.
  - gwd's log to stdout (-log -), so to journald.
  - Out of chain (under git): bxGenesis/start/rawBisosCBMs/README.org (the catalog: geneweb enabled,
    raw platform); the cbm-package-authorship skill.
